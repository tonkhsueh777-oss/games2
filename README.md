# 灯隙 · 手机竖屏互动影游

先完整加载8份独立影片，再进入游戏。包含剧情选择、商店、手势战斗、折骨灯收核封印及三个结局。

首次约3.9MB（原版10.3MB，减少约62%），加载进度按实际下载字节更新；断线自动重试，当前页面内按字节续传；已完成影片保留。全部影片完成长度与SHA-256校验后开启入口，运行时使用已下载的Blob资源。浏览器允许时缓存影片供下次打开复用。

这是依据玩法说明和用户提供影片重建的V0.5，未取得旧原型ZIP。音轨保留原片，已通过WebKit的iPhone尺寸测试，手机真机及用户所在网络仍待验证。

部署方式：GitHub Pages，main分支根目录。

## 手机加载修复

不使用loadeddata事件判定下载完成，避免手机省流量模式下误报解码失败。小体积影片位于media/mobile-v2；保留原始影片供旧版兼容。网络停滞90秒触发重试，最多自动重试3次，当前页面保留已收字节；服务器不支持Range时才重新下载该段。重新打开页面只复用已完整缓存的影片。

缓存页面采用在线优先、离线回退，避免一直使用旧加载脚本。
